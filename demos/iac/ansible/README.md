# Ansible Demos

Demos de configuration management con Ansible.

## Cómo agregar

1. Crear `ansible/<nombre-demo>/`
2. Agregar `README.md`, `playbook.yml`, `inventory.ini` (o `inventory.example`)
3. Agregar `group_vars/` con variables (usar `.example` para secrets)
4. Commit con `feat: agregar demo ansible <nombre>`
