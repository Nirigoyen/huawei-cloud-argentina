# Infrastructure as Code — Demos

Demos de infra usando Terraform y Ansible.

## Estructura

- [`terraform/`](terraform/) — Demos con Terraform (provisioning de cloud resources)
- [`ansible/`](ansible/) — Demos con Ansible (configuration management)

## Uso

Cada demo tiene su propio `README.md` con instrucciones. Los demos de Terraform requieren credenciales del cloud provider configuradas. Los de Ansible requieren acceso SSH a los target hosts.
