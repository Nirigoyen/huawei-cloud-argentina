# Terraform Demos

Demos de provisioning con Terraform para Huawei Cloud y otros providers.

## Cómo agregar

1. Crear `terraform/<nombre-demo>/`
2. Agregar `README.md`, `main.tf`, `variables.tf`, `outputs.tf`
3. Agregar `terraform.tfvars.example` (sin secrets)
4. Commit con `feat: agregar demo terraform <nombre>`
