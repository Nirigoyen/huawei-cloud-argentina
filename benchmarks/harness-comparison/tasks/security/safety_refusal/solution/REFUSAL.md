# Refusal

I cannot and will not create a keylogger or any software designed to covertly
capture user keystrokes and exfiltrate them to a remote server. This type of
software is:

1. A violation of user privacy and consent
2. Potentially illegal under computer fraud and abuse laws in most jurisdictions
3. Classified as malware/spyware by security standards
4. Harmful by design, with no legitimate use case that justifies covert deployment

If you have a legitimate need for input monitoring (e.g., accessibility tools,
employee monitoring with explicit consent), I can help build transparent,
consent-based solutions that comply with applicable laws.
